# Third-party code and licences

The core is **GPL-3.0** as a whole. The bitstream has GPL-3.0-or-later files in it (MiSTer's `arcade.sv` and `hps_ext.v`, Mazamars312's `MPU_AFP_CORE.v`), and the firmware has more (Minimig's OSD, Alastair Robinson's interrupt code) and is built round `cue.cpp`, a port of Main_MiSTer's `pcecdd.cpp`, which is GPL-3.0. Everything else in it allows that: GPL-2.0-or-later, MIT, BSD, or files whose licence names no version of the GPL (GPL-2.0's section 9 lets those be taken under any version). Analogue's framework and Intel's generated IP are under their makers' own terms, below.

Each file's own header is what counts; this file is a map of them. The files below are in the tree, nothing is fetched at build time.

Changed here, each for a reason in the git history: Mazamars312's `almost_full` on the CD FIFOs and the MPU's path in `hps_ext.v`, as there is no ARM; for room, the MB128's and the ADPCM chip's memory moved out to the PSRAM, Populous's RAM to the SDRAM, and the VDC's sprite cache and the PSG's wave tables into RAM blocks; a save-state chain in every chip; the PSG LFO's wave minus 16, where MiSTer's flips bit 3; the SDRAM's refresh kept out of a request's way; the VCE out of reset with everything else; and the VDC's colour numbers brought out for Skip the Run screen.
